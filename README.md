# 🌿 สวนความทรงจำ (Memory Garden)
> **เว็บแอปพลิเคชันคัดกรองภาวะรู้คิดบกพร่องเล็กน้อย (MCI) และความเสี่ยงโรคอัลไซเมอร์เบื้องต้น**  
> *พัฒนาขึ้นเพื่อผู้สูงอายุและครอบครัว ใช้งานง่ายด้วยเสียงพูดภาษาไทยและธีมธรรมชาติที่ผ่อนคลาย*

---

## 📌 ภาพรวมโครงการ (Project Overview)

**สวนความทรงจำ (Memory Garden)** เป็นเว็บแอปพลิเคชันที่ออกแบบมาเพื่อประเมินสมรรถภาพการทำงานของสมอง (Cognitive Assessment) แบบ Gamified Screening Tool โดยอ้างอิงตามเกณฑ์มาตรฐานการตรวจทางประสาทวิทยา เช่น **MoCA (Montreal Cognitive Assessment)** และ **MMSE (Mini-Mental State Examination)** โดยจำลองบรรยากาศการเดินเล่นในสวนธรรมชาติเพื่อลดความเครียดและความวิตกกังวลของผู้เข้ารับการทดสอบ

---

## 🎯 วัตถุประสงค์หลัก

1. **คัดกรองภาวะสมองเสื่อมระยะแรก (Early Detection)**: ช่วยตรวจหาความเสี่ยงภาวะรู้คิดบกพร่องเล็กน้อย (Mild Cognitive Impairment: MCI)
2. **เข้าถึงง่ายและเป็นมิตรต่อผู้สูงอายุ (Elderly-Friendly UI/UX)**: ตัวหนังสือขนาดใหญ่ มีปุ่มกดเลือกคำตอบ และมีระบบเสียงอ่านคำสั่งภาษาไทย (TTS)
3. **ส่งต่อสู่การรักษาที่รวดเร็ว (Care Pathway)**: แนะนำโรงพยาบาลและคลินิกความจำเฉพาะทางที่ใกล้ที่สุด พร้อมเบอร์โทรและแผนที่นำทาง
4. **เก็บบันทึกและติดตามผล (Longitudinal Tracking)**: บันทึกประวัติคะแนนเพื่อติดตามแนวโน้มสุขภาพสมองในระยะยาว

## 📊 โครงสร้างการประเมิน 5 ด้าน (คะแนนเต็ม 30 คะแนน)

                              └─────────────────┬─────────────────┘

         │                  │                   │                   │                  │

│  🧠 1. ความจำ   │ │ 🕰️ 2. มิติสัมพันธ์│ │  🛒 3. สมาธิ/เลข │ │  🌿 4. ภาษา      │ │ 🗺️ 5. วันเวลา/ที่│

|:---:|---|---|---|:---:|
| **1** | 🧠 **ด้านความจำระยะสั้น (Delayed Memory Recall)** | ฟัง/อ่านเรื่องราวในสวนและจดจำสิ่งของ 5 อย่าง นำมาระลึกตอบในช่วงท้าย | 5 คำศัพท์ในสวน | **5 คะแนน** *(คำละ 1 คะแนน)* |

| **4** | 🌿 **ด้านภาษา (Language)** | รวม 3 กิจกรรมประเมินภาษาตามมาตรฐาน MoCA: | • **Naming (บอกชื่อสิ่งของ):** 5 ภาพ (5 คะแนน)<br>• **Sentence Repetition (พูดซ้ำประโยค):** 2 ประโยค (2 คะแนน)<br>• **Category Fluency (ความคล่องแคล่ว):** บอกชื่อสัตว์ใน 60 วินาที (4 คะแนน) | **11 คะแนน** |
| **5** | 🗺️ **ด้านการรับรู้วันเวลาและสถานที่ (Orientation)** | ระบุวันที่, เดือน, ปี พ.ศ., วันในสัปดาห์, ช่วงเวลาปัจจุบัน และจังหวัดที่อาศัยอยู่ | วันที่, เดือน, ปี, วัน, ช่วงเวลา, จังหวัด (ข้อละ 1 คะแนน) | **6 คะแนน** |

> หากผู้รับการประเมินมีระดับการศึกษา $\le$ 12 ปี (ระดับประถมศึกษาหรือต่ำกว่า ม.6) ระบบจะบวกคะแนนเพิ่ม **+1 คะแนน** ตามมาตรฐาน MoCA (คะแนนรวมสูงสุดไม่เกิน 30 คะแนน)

## 📈 เกณฑ์การแปลผลและระดับความเสี่ยง (Risk Stratification)

| ช่วงคะแนน | ระดับผลการประเมิน | คำอธิบายและการดูแล |
|:---:|:---:|---|
| **25 – 30 คะแนน** | 🟢 **ปกติ (Normal)** | สุขภาพสมองอยู่ในเกณฑ์ดี แนะนำให้ออกกำลังกาย สังสรรค์ และทำกิจกรรมฝึกสมองสม่ำเสมอ |
| **18 – 24 คะแนน** | 🟡 **เสี่ยงบกพร่องเล็กน้อย (MCI Risk)** | เริ่มพบสัญญาณการทำงานของสมองลดลง แนะนำให้ปรึกษาแพทย์เพื่อตรวจวินิจฉัยอย่างละเอียด |
| **< 18 คะแนน** | 🔴 **ควรได้รับการดูแลพิเศษ (High Risk)** | มีข้อจำกัดในการทำงานของสมองหลายด้าน แนะนำให้ญาติพาไปพบแพทย์เฉพาะทางหรือคลินิกความจำ |

## ✨ ฟีเจอร์เด่นของระบบ (Key Features)

### 1. 🔊 ระบบเสียงอ่านคำสั่งและคำแนะนำ (Text-to-Speech)
- ใช้ **Web Speech API** ภาษาไทย (`th-TH`) 
- ปรับความเร็วการพูดช้าลง (`rate: 0.85 - 0.9`) เพื่อให้ผู้สูงอายุฟังเข้าใจง่าย
- มีปุ่มลำโพง `🔊` ในทุกหน้าเพื่อให้ฟังซ้ำได้ตลอดเวลา

### 2. 💡 ระบบคำใบ้แบบไล่ระดับ (Multi-Stage Progressive Hint)
สำหรับด่านระลึกความจำ (Recall Test) มีระบบคำใบ้ 3 ระดับ:
- **ระดับ 1 (Pattern Hint)**: แสดงอักษรตัวแรกและตัวท้าย เช่น `ต _ _ _ ม้`
- **ระดับ 2 (Semantic Hint)**: แสดงประโยคบริบทของคำศัพท์
- **ระดับ 3 (Audio Hint)**: อ่านออกเสียงตัวอย่างคำศัพท์ (TTS)
*(หมายเหตุ: การกดขอคำใบ้จะไม่ได้รับคะแนนในข้อนั้น เพื่อคงความเที่ยงตรงทางคลินิก)*

### 3. 🏥 ระบบค้นหาโรงพยาบาล/คลินิกความจำใกล้ฉัน (Memory Clinic Locator)
- ใช้พิกัด **GPS (Geolocation API)** คำนวณระยะทางจริงด้วยสูตร **Haversine Formula**
- แสดงผลโรงพยาบาลศูนย์และคลินิกความจำเฉพาะทางที่ใกล้ที่สุด
- มีปุ่ม **📞 โทรศัพท์ติดต่อ** และ **📍 แผนที่นำทาง Google Maps** ในคลิกเดียว

### 4. 🪪 ระบบประวัติส่วนบุคคลและเชื่อมต่อ LINE Login
- สร้างรหัสประจำตัว **User ID** เพื่อใช้ติดตามผลและแสดงต่อแพทย์
- รองรับการเข้าสู่ระบบผ่าน **LINE LIFF** สะดวก ไม่ต้องจำรหัสผ่าน
- บันทึกประวัติและกราฟแนวโน้มคะแนนย้อนหลังผ่านฐานข้อมูล **Supabase**

### 5. 🔐 แดชบอร์ดผู้ดูแลระบบและแพทย์ (Admin Dashboard)
- เข้าสู่ระบบ Admin ได้ที่ `admin.html`
- บันทึกคะแนนเทียบเคียงกับผลตรวจบนกระดาษ (**Paper MoCA Score**)
- คำนวณสถิติวิจัยความแม่นยำทางคลินิกอัตโนมัติ:
  - **Sensitivity & Specificity**
  - **ROC Curve & AUC**
  - **Spearman Rank Correlation ($r_s$)**
  - **Diagnostic Accuracy & MAE**
  - **Optimal Cut-off Score (Youden's Index)**

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

- **Frontend**: HTML5, Vanilla JavaScript (ES6+), Vanilla CSS3 (Modern Glassmorphism & Micro-animations)
- **Visuals & Fonts**: Google Fonts (*Anuphan*, *Prompt*), Responsive Flexbox & Grid Layout
- **Database & Backend**: [Supabase](https://supabase.com/) (PostgreSQL & Storage)
- **Identity & Social**: LINE Front-end Framework (LIFF SDK)
- **Data Analytics & Charts**: [Chart.js](https://www.chartjs.org/) (Scatter Plots, ROC Curves, Percentile Ranks)
- **APIs**: Web Speech Synthesis API, Geolocation API

## 🚀 วิธีการติดตั้งและรันโครงการ (Getting Started)

### ความต้องการของระบบ:
- [Node.js](https://nodejs.org/) (เวอร์ชัน 18 ขึ้นไป)

### ขั้นตอนการรัน:

1. **ติดตั้ง Dependencies**:
   ```bash
   npm install
   ```

2. **เริ่มเซิร์ฟเวอร์สำหรับพัฒนา (Dev Server)**:
   ```bash
   npm run dev
   ```

3. **เข้าใช้งาน**:
   - หน้าผู้ใช้งานทั่วไป: `http://localhost:5173/` หรือ `index.html`
   - หน้าผู้ดูแลระบบ: `http://localhost:5173/admin.html`
